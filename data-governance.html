统计表格导出（CSV）

研究级扁平表 · 供 SPSS/R 等统计软件读取

四张表：participant_wide（每被试一行，canonical 结果 + site/consent 合并，主分析表）；attempts（全部作答尝试，含 invalid，带 is_canonical 与 QC 列）；provenance（研究层 attempt 溯源）；audit_log（治理审计链，含本次导出记录）。

隐私边界：CSV 只含计数与分值；自由作答原文（语义流畅词条、开放题回答）与私有素材内容不入表，仍随 JSON bundle 保留。

CSV 格式规范

research-table-export 1.0.0

UTF-8 带 BOM · RFC 4180（CRLF 换行，含逗号/引号/换行的字段加引号，内部引号加倍）· null → 空字段 · 布尔 → 0/1 · 列名英文 snake_case，SPSS 兼容。

审计链：每次表格导出写入一条 table_exported 记录（表名 / 行数 / 操作者 / 导出版本）到研究审计链，并随 JSON bundle 一起导出。

BIDS 风格 TSV 有意推迟（v1.1.0 候选）：尚无真实消费者，避免死代码。

受控导入 / 恢复

先验证，再应用

先选择导出的 research-data bundle；只有通过结构校验后才允许应用。

撤回与删除

语义不同，不自动混用

撤回：保留审计和既有数据，阻止后续 session。
硬删除：从本地 participant + research provenance 中移除该参与者关联记录；若启用 replica，可再显式请求远端删除。

参考后端用于验证认证 API、原子 JSON 写入与备份契约；不等同于生产研究数据平台。
