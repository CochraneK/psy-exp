## MCCB 全套测验 — User/Dev 双模式切换机制实现

### 目标
为 MCCB 认知测验套件的每个测试页面实现 `?mode=dev` / `?mode=user` 参数驱动的双模式切换，User Mode 下隐藏所有开发辅助元素（反馈面板、正确/错误标记、统计信息等），使界面干净、只保留核心测验功能。

### 架构设计
- **`index.html`**：入口文件，新增 DEV/USER 切换开关（toggle button），模式存入 `localStorage`，`goTest(href)` 从 localStorage 读取模式并附加 `?mode=...` URL 参数
- **每个测试页**：从 URL 解析 `mode` 参数，定义全局常量 `IS_DEV`，通过 `applyModeStyles()` 在 User Mode 下隐藏开发辅助 DOM 元素
- **模式传递链路**：`index.html` toggle → localStorage → URL param (`?mode=dev|user`) → 测试页解析 → `IS_DEV` + `applyModeStyles()`

### 完成文件（共 10 个测试页 + 1 个入口页）

4. `mccb-fluency.html` — 完整模式注入

9. `mccb-msceit.html` — 完整模式注入（含 feedbackArea 隐藏 + correct-answer/wrong-answer 类守卫）

11. `mccb-bvmt.html` — 模式注入（本日完成，纯绘画/回忆测验）

### 统一注入模式
每个测试页添加以下代码块：
```javascript
// === Mode (DEV / USER) ===
const urlParams = new URLSearchParams(window.location.search);
const MODE = urlParams.get('mode') || 'dev';
const IS_DEV = MODE === 'dev';
function applyModeStyles() {
  if (!IS_DEV) {
    // 隐藏开发辅助 DOM 元素
  }
}
```

并确保在初始化流程中调用 `applyModeStyles()`。
