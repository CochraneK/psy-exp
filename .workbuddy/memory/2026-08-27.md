## MCCB 连线测验 (Trail Making Test) 电子版开发

### 背景
用户调研了MCCB（MATRICS Consensus Cognitive Battery）中的连线测验（Trail Making Test），希望制作一个电子版用于心理学实验。

### 调研要点
- TMT分为Part A（数字1-25连线）和Part B（数字-字母交替连线 1-A-2-B-...-13）
- Part A评估处理速度、视觉扫描和注意力
- Part B评估执行功能、认知灵活性、任务切换
- 主要指标：完成时间（秒），辅助指标：错误次数
- 派生指标：B-A差值（执行功能时间成本）、B/A比值（>3提示执行功能受损）
- MCCB标准：Part A上限100秒，Part B上限300秒

## CPT-IP Report Generator — 4-digit 数据块解析 Bug 修复

**问题**：生成的 HTML 报告中 4 位数字（4-digit）条件行所有数据为 `—`（缺失）。

**根本原因**：`cpt_report.py` 第41行 4-digit regex 用超前断言 `(?=\n\n\s*\Z)` 锚定到文件结尾，要求数据块后两个换行后只跟空白字符到文件末尾。但 `.trep` 文件中 4-digit 数据块后实际是 `\n\n\nDPRIME (USING FALSE ALARMS) = X.XXXX\n`（含非空白字符），超前断言永远不匹配，`4digit` block 整个未被捕获。

**修复**：将 regex 从 `r'4-Digit Numbers.*?\n(.*?)(?=\n\n\s*\Z)'` 改为 `r'4-Digit Numbers.*?\n(.*?)\Z'`，直接锚定到字符串结尾，DPRIME 行被包含在 block_text 中供后续 dprime 提取。

## MCCB TMT 自我检查提升

在完成初始版本后，应要求进行了全面的代码质量审查和改进，共实施 7 项改进：

1. **修复计时器启动时序 Bug** — Part A 练习的计时器原来在 `startPart()` 中立即启动，先于遮罩层出现。改为将计时器启动移到遮罩层按钮的 `cb` 回调中。

2. **添加点击锁定机制** — 引入 `STATE.clickLock` 布尔标志，`onCanvasClick` 入口检查锁定，处理完毕后（或错误闪烁 200ms 后）释放，防止快速点击导致并发重绘的竞态条件。

3. **修复标签随机打乱** — 此前标签按网格顺序映射到位置，相邻数字空间相邻导致测试难度丧失。新增 `createShuffledPoints()` 用独立种子（137）打乱标签到位置的分配，实现真正的随机排列。

4. **添加 MCCB 时间限制** — Part A 上限 100 秒，Part B 上限 300 秒（MCCB 标准）。`handleTimeout()` 生成专门的超时遮罩页，记录已完成的点击数和部分结果。

5. **重构 drawScene 性能** — 将 `resizeCanvas()` 从 `drawScene()` 中移除；调整大小仅在初始化时和防抖的窗口 resize 处理器中执行，减少不必要的 DOM 重排。

6. **添加数据导出功能** — 结果页新增"导出数据"按钮，提供 JSON/TXT 下载 + 剪贴板复制三种方式。JSON 包含所有逐次点击数据（目标、反应时、错误标记），TXT 为可读性报告格式。

7. **添加逐次点击反应时记录** — 测试阶段每次点击记录 `{target, index, reactionTime, error}` 到 `STATE.clickData` 数组，为后续精细分析（如位置效应、疲劳效应）提供数据基础。

8. **添加常模对照参考** — `interpretResults()` 函数输出完成时间的定性解释（正常/边缘/轻度受损等），并在结果页展示常模提示。

额外增强：触屏支持（`touchstart`）、键盘可访问性（Enter/Space）、窗口 resize 防抖（150ms 延迟）。

## CPT-IP Report — Chart.js → 内联 SVG 迁移

**问题：** HTML 报告通过 `file://` 打开时，Chart.js CDN 被浏览器的 Tracking Prevention 拦截（unique opaque security origin），图表空白。

**方案：** 完全移除 Chart.js CDN + JavaScript，改为 Python 端直接生成内联 SVG 图表：
- `_make_svg_bar_grouped()` — 分组/单组柱状图，支持多数据集图例
- `_make_svg_line_chart()` — 折线图，带填充区域和圆点标记
- 生成的 HTML 无任何 `<script>` 标签，14.7 KB，可在 `file://` 协议下完美运行

### CPT-IP 持续操作测验设计
- **认知域**：注意力/警觉性 (Attention / Vigilance)
- **规则**：快速呈现 4 位不重复数字（400ms 显示 + 700ms 间隔），与前一个相同则按空格键
- **结构**：10 次练习 → 150 次正式测验，~28% 为目标试次
- **指标**：命中数、漏报数、虚报数、正确否定数、辨别力指数 d'、反应时
- **反馈**：试次间快速反馈（✓/✗ 动画），结束后完整结果页显示 d' 值和反应时统计
- **数据导出**：JSON 格式导出全部 trial 级数据和汇总统计
