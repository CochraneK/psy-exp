MCCB 认知成套测验报告

⚡ 处理速度 Processing Speed 3 项测验
#1 —
TMT 连线测验 Trail Making Test: Part A
按数字顺序 1→2→3→…→25 依次点击圆圈。评估视觉搜索速度和注意力。
处理速度 注意力 ~5 分钟
#2 —
BACS 符号编码 BACS Symbol Coding
90 秒内根据符号-数字对照表快速编码。评估处理速度和注意力。
处理速度 ~3 分钟
#3 —
语义流畅性 Category Fluency: Animal Naming
60 秒内尽可能多地说出动物名称。评估言语流畅性和语义记忆检索能力。
处理速度 ~3 分钟
🎯 注意力 / 警觉性 Attention / Vigilance 1 项测验
#4 —
CPT-IP 持续操作测验 Continuous Performance Test — Identical Pairs
快速判断连续出现的数字对是否相同。评估持续注意力和警觉性。
注意力 ~5 分钟
💭 工作记忆 Working Memory 2 项测验
#5 —
WMS-III 空间广度 WMS-III Spatial Span
按顺序（或倒序）点击逐渐变长的方块序列。评估视觉空间工作记忆。
空间记忆 注意力 ~5 分钟
#6 —
字母-数字广度 Letter-Number Span (LNS)
将听到的数字和字母按"数字从小到大，字母按字母顺序"重新排列。评估言语工作记忆。
言语记忆 推理 ~5 分钟
📖 言语学习 Verbal Learning 1 项测验
#7 —
HVLT-R 言语学习测验 Hopkins Verbal Learning Test — Revised
3 轮学习 + 延迟回忆：记忆 12 个单词，评估言语学习和记忆能力。
言语学习 记忆 ~10 分钟
👁️ 视觉学习 Visual Learning 1 项测验
#8 —
BVMT-R 视觉空间记忆 Brief Visuospatial Memory Test — Revised
记忆并复现 6 个几何图形的位置和形状。评估视觉空间学习与记忆。
视觉学习 空间记忆 ~10 分钟
🧩 推理与问题解决 Reasoning & Problem Solving 1 项测验
#9 —
NAB 迷宫 NAB Mazes
在迷宫中从起点走到终点，评估执行功能、规划和问题解决能力。
执行功能 推理 ~10 分钟
🤝 社会认知 Social Cognition 1 项测验
#10 —
MSCEIT 情绪管理 Mayer-Salovey-Caruso Emotional Intelligence Test: Managing Emotions
评估理解和管理情绪的能力，面对情境选择最有效的情绪调节策略。
社会认知 ~8 分钟
