# MCCB 工作台 · 演示站（100% 合成数据）

> **本目录全部为程序生成的演示数据与演示站**：13 个演示项目 / 346 名合成受试者（演示0001…）/ 约 700 次访视，
> 姓名、ID、分数均为随机合成（固定种子 `20261028`，可复现），**不含任何真实受试者信息**。
> 用于展示工作台的功能形态（图表、分组对比、KW 显著性、项目/个人深链）与验证管线。

## 打开

直接浏览器打开 `mccb_dashboard.html`（零联网，离线可用）。

## 重新生成

```bash
pip install -r ../requirements.txt
python docs/_make_demo.py
```

流程：合成 `docs/data/*.xlsx`（13 个文件，与真实导出同表头）→ 内存中重定向 `refresh.py` 的输出路径后完整跑一遍真实管线 → 覆写本目录的 `mccb_dashboard.html` / `person.html` / `reports/`。`refresh.py` 本体零改动。

## 演示数据口径

- 13 个演示项目 → 9 个诊断分组（健康对照 / 精分 / 抑郁 / 双相 / 强迫 / HDN / 神经调控 / 独立项目 / 其他）
- 346 名合成受试者，年龄 18–58（仅成人），2019-11 ~ 2026-09
- 按分组设能力基线（对照≈52 / 精分≈43 / HDN≈42 …），神经调控 / tDCS 演示组带纵向改善趋势（展示干预前后对比图）
- `test_演示1/2` 文件名命中 `TEST_FILE_HINTS`，演示「仅统计正式项目」开关
- `tDCS演示` 用 `AGET` 后缀列，演示 `AGT/AGET` 模糊匹配路径
